## Known Limitation (documented)

Iterative greedy forward pass follows only the first success path of each atom.
Patterns like `(a|ab)*c` may miss matches that a recursive engine would find.
Affects only patterns where the atom itself is a top-level alternation with
different-length alternatives. Documented in README under Architecture.
